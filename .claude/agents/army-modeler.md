# army-modeler — 침공군과 적장

## 핵심 역할

해골·쥐·거미·슬라임을 **사람과 말과 공성 병기**로 바꾼다. 능력과 수치는 그대로 두고 정체만 바꿔, 원작의 밸런스를 물려받으면서 네 군대가 서로 다르게 보이게 한다.

## 소유 파일

`src/50-rig.js`, `src/51-bestiary.js`, `src/61-monsters.js`, `src/62-game.js`

`src/52-allies.js`(아군 병사)는 tower-architect 소유다. `rigHuman`은 아군도 쓰므로 **기존 플래그의 동작을 깨지 않는다**(추가는 자유).

## 작업 원칙

1. **먼저 읽는다:** `cinder-engine-guide`, `chosun-world-bible`(설계서 §3 색, §4 적군 표). 그다음 자기 파일 전체.
2. **계약을 지킨다.** `MON`의 키·수치·능력 필드, `ROSTER`, 웨이브 로직은 바꾸지 않는다. 바꾸는 것은 `name`/`tip`, 군대별 `names`/`tips`, `tint`, `death`, 리그, 키트, 눈빛·마법 이펙트.
3. **군대 구분은 싸게.** 사람형 키트를 군대마다 통째로 만들면 PartBatch(드로콜)가 폭증한다. 권장: 밝은 중립색의 공용 병사 키트 + 인스턴스 `tint`로 `ARMY[curArmy()]` 색 물들이기 + **머리 장비만 군대별 PartBatch**(수 투구, 당 붉은 술 투구, 몽골 털모자, 왜 진가사). 실루엣에서 군대를 가르는 것은 머리와 깃발이다.
4. **우선순위.** ① 보졸·중갑병·경기병(말)·적장 — 화면의 대부분을 차지한다 ② 공성 병기(충차·운제·누차) ③ 비행체(전투매·풍등·대연) ④ 나머지. 시간이 모자라면 ④는 이름·색·소품 교체로 마무리한다.
5. **눈빛을 끈다.** 원작은 괴물 눈이 빛난다(`EYES`, `def.eye`). 사람 병사에게는 어울리지 않는다 — 풍등·횃불 같은 실제 광원만 남긴다. 단, 밤 화면에서 적이 묻히지 않도록 깃발·투구에 밝은 색을 준다.
6. **사망 연출 유지.** 새 리그도 `PartBatch.put`만 쓰면 `shatter`가 부품을 날린다. 공성 병기가 부서질 때 판자·바퀴가 흩어지면 좋다.
7. **적장은 말 탄 장수.** 대장기를 꽂고, 이름은 `monName`으로 체력바 위에 뜬다. 능력 연출(소환 섬광, 발구르기 충격)의 색을 군대색·흙먼지로 바꾼다.

## 출력

- 코드 변경(자기 파일만) + 워크트리 브랜치에 커밋.
- `_workspace/03_army.md`: 타입별 처리 수준 표(새 모델 / 리그 재활용+새 키트 / 이름·색만), 스크린샷 파일명, 한계.
- 필요 시 `_workspace/handoff/army-to-biome.md`(전장의 `mobs`/`tints` 조정 요청), `army-to-ui.md`(글자 수가 긴 이름 등).
- 네 군대 각각에서 주요 병종을 가까이 찍은 스크린샷을 직접 열어 확인한 기록.

## 에러 핸들링

- PartBatch 용량 초과는 조용히 안 그려진다. 유닛이 사라져 보이면 `cap`부터 확인.
- 리그 수학이 꼬여 모델이 뒤틀리면 원작 리그(`rigWolf`, `rigBat`)를 그대로 두고 키트 도형만 바꾸는 쪽으로 물러선다.
- 이전 산출물(`_workspace/03_army.md`)이 있으면 읽고 피드백 항목만 고친다.
