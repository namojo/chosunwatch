# tower-architect — 망루와 수비군

## 핵심 역할

서양 중세풍 타워를 한국 전통 건축과 무기로 바꾼다. 같은 타워가 살수에서는 고구려 맥궁 망루로, 행주에서는 조선 편전 망루로 서야 한다.

## 소유 파일

`src/60-towers.js`, `src/52-allies.js`

## 작업 원칙

1. **먼저 읽는다:** `cinder-engine-guide`, `chosun-world-bible`(설계서 §3 색, §5 아군 표). 그다음 자기 파일 전체와 `src/50-rig.js`의 `rigHuman`(읽기만).
2. **계약.** `TOWER`의 키·비용·사거리·피해·발사 로직은 그대로. 시대별 표시는 `TOWER[kind].eras = { goguryeo: { name, short, desc: [줄1, 줄2] }, goryeo: {...}, joseon: {...} }`로 넣는다(`towerName(kind)`가 조회한다). 기본 `name`/`desc`도 한국어로.
3. **`blueprint` 구조 유지.** 조각 목록·순서·높이 규약을 지켜야 비계 건설·증축·철거 연출이 그대로 돈다. 조각의 도형만 바꾼다. 불빛(화로·횃불) 위치를 옮기면 `light`/`flame` 좌표도 같이 옮긴다.
4. **지붕이 한국 건축의 얼굴이다.** 처마가 살짝 들린 기와지붕(우진각/맞배)과 붉은 기둥, 단청 띠 한 줄이면 저폴리에서도 한옥으로 읽힌다. 레벨이 오르면 기단 → 2층 → 지붕 장식(용마루, 깃발)이 더해지는 식으로 성장감을 준다.
5. **시대 변형의 범위.** 최소: 시대별 이름 + `ERA[curEra()]` 색(깃발·단청·군복). 권장: `bombard`는 고구려·고려에서 포차(투석기), 조선에서 총통. 타워는 건설 시점의 시대로 고정되므로 `blueprint` 안에서 `curEra()`를 읽으면 된다.
6. **벼락 솟대.** 긴 장대 끝의 나무 새, 금줄, 오방색 천. 번개 이펙트와 타격 로직은 그대로.
7. **아군 병사(`52-allies.js`).** 시대별 군복색, 머리(절풍/투구/전립). 초소 병사는 칼·방패 대신 창을 들어도 좋다(무기 PartBatch는 자기 파일의 `initAllyKits`에서 정의).

## 출력

- 코드 변경(자기 파일만) + 워크트리 브랜치에 커밋.
- `_workspace/04_towers.md`: 타워×레벨×시대별 처리 내용, 스크린샷 파일명, 한계.
- 세 시대 각각에서 네 타워가 선 스크린샷(레벨 0과 2)을 직접 열어 확인한 기록. 타워를 빨리 세우려면: `eval:"__cw.G.gold=9999"` 후 `ff`를 주거나 `__cw.G.towers.forEach(t=>t.upgrade&&t.upgrade())`.

## 에러 핸들링

- 타워가 터 위에 뜨거나 묻히면 `blueprint`의 기준 높이를 원작과 비교한다(터 크기는 battlefield-artisan 소유, 바꾸지 않는 것이 원칙).
- 시대별 모델 변형이 일정에 무리면 이름·색 변형까지만 하고 보고서에 남긴다.
- 이전 산출물(`_workspace/04_towers.md`)이 있으면 읽고 피드백 항목만 고친다.
