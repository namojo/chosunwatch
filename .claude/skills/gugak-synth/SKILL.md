# 국악 합성 가이드

`src/80-audio.js`의 `AU`는 샘플 파일 없이 오실레이터·노이즈·필터로 모든 소리를 만든다. 이 원칙을 지키면서 서양 관현악 어휘(호른, 팀파니, 피아노 패드)를 국악 어휘로 바꾼다.

## 건드리지 않는 것

- 공개 API(`AU.unlock/setMuted/setPaused/play/setAmbience/update`, `AU.ready`, `AU.muted`)와 `play(name, …)`의 **효과음 이름 키**. 다른 모듈이 `sfx('horn')`, `sfx('hornBoss')`, `sfx('ignite')`처럼 이름으로 부른다. 이름은 두고 소리만 바꾼다.
- 동시 발음 수 관리(`voice`/`finishVoice`)와 음량 버스 구조. 전투 중 수십 개의 소리가 겹치므로 원작의 제한 로직을 우회하면 클리핑·끊김이 난다.
- 게임 상태가 필요하면 `AU.update` 안에서 전역 `G`(같은 번들 스코프)를 읽는다: `G.phase`, `G.bossWave`, `G.B.bio.key/era/army`, `G.lives/G.maxLives`. 다른 파일에 호출을 추가하지 않는다.

## 음계

서양 화성 진행(패드 코드)을 버리고 **지속음(드론) + 5음 선율**로 간다.

| 음계 | 구성(으뜸음 기준 반음) | 쓰임 |
|---|---|---|
| 평조(솔 선법) | 0, 2, 5, 7, 9 | 밝고 당당 — 고려·조선 전장, 승전 |
| 계면조(라 선법) | 0, 3, 5, 7, 10 | 비장·애절 — 고구려 전장, 위기, 패전. 3음(0과 3 사이)은 굵게 떨고 5→3은 꺾어 내린다. |

- 전장별 으뜸음을 달리해 다섯 전장의 색을 나눈다(예: 살수 D 계면, 안시성 E 계면, 귀주성 A 계면 낮게, 진주성 G 평조+불협 드론, 행주 C 평조).
- **시김새**가 국악처럼 들리게 하는 핵심이다: 음 시작에 아래에서 밀어 올리는 짧은 글리산도(`frequency.setValueAtTime(f*0.94)` → `exponentialRampToValueAtTime(f, t+0.06)`), 긴 음의 느리고 깊은 농현(4~6Hz, ±20~40센트, 뒤로 갈수록 깊게), 음 끝의 꺾는 음(−반음 급강하).

## 음색 레시피

| 악기 | 합성 |
|---|---|
| **북(전고)** | 사인 피치 드롭 90→48Hz(0.12s) + 짧은 저역 노이즈 버스트(LP 300Hz, 20ms). 감쇠 0.5s. 원작 `timp`/`whoomp` 재활용. |
| **장구 덩(양손)** | 북편(사인 110→70Hz) + 채편(밴드패스 노이즈 1.8kHz, Q 3, 30ms)을 동시에. **쿵**=북편만, **덕**=채편만, **기덕**=채편 겹침(25ms 간격). |
| **징** | 비정수 배음 사인 5~6개(기음 ~180Hz × 1, 1.48, 2.1, 2.76, 3.4…)에 느린 맥놀이(각 배음 ±0.7Hz 쌍), 타격 후 피치가 살짝 **올라가는**(+15센트, 0.4s) 특성, 감쇠 4~6s. 적장 등장·패전. |
| **꽹과리** | 고역 비정수 배음(기음 ~900Hz) + 밴드패스 노이즈, 감쇠 0.15s(막음)/0.6s(울림). 승전·건설 완료의 반짝임. |
| **나발** | 톱니파 단일음(Bb2~Bb3) + 로우패스 스윕(300→1.4kHz, 0.25s) + 약한 포화. 음정 변화 없이 길게 한 음. 공세 신호(`horn`). |
| **나각(소라)** | 사인+삼각파, 숨소리 노이즈 약간, 시작에 5도 아래에서 밀어 올림. `hornBoss`에 나발과 징을 겹친다. |
| **태평소** | 펄스/톱니 + 밴드패스 2개(1.1kHz, 2.6kHz, Q 6)로 콧소리 포먼트, 빠른 농현. 적장전 선율 — 시끄러우므로 음량 낮게. |
| **대금** | 삼각파 + 하이패스 숨소리 노이즈, 청 떨림(고음에서 3kHz 밴드 노이즈를 음량에 연동). 평상시 선율. |
| **가야금** | 톱니/삼각 짧은 뜯음(감쇠 1.2s) + 로우패스 스윕, 뜯은 뒤 농현. 원작 `pianoNote` 자리. |

## 장단 — 긴장도(`tension`)에 묶기

원작 `musicTick`은 긴장도에 따라 팀파니를 넣는다. 이를 장단 스텝 시퀀서로 바꾼다(12/8 기준 12칸).

| 긴장도 | 장단 | 빠르기 | 패턴(덩=D, 쿵=K, 덕=T, 기덕=G, 쉼=·) |
|---|---|---|---|
| 낮음(대기) | 없음, 드론+대금 독주 | — | — |
| 중간(공세) | 자진모리 | ♩.≈96 | `D · · K · · K · T K · ·` |
| 높음(적장·봉화 위태) | 휘모리 | ♩≈150 (4/4, 8칸) | `D · T K · T K ·` + 북 정박 |
| 승전(전장 돌파) | 풍물 한 가락 | 휘모리 2마디 + 꽹과리 `갱 갠지 갱 갠지`, 징 한 번 |

장단은 정확한 격자보다 **살짝 밀고 당기는 맛**(±8ms 무작위, 강박 음량 차)이 있어야 기계음처럼 들리지 않는다.

## 효과음 재해석

| 키(불변) | 원작 | 조선워치 |
|---|---|---|
| `horn` | 호른 | 나발 긴 한 음 + 북 한 번 |
| `hornBoss` | 낮은 호른 | 나각 + 징 + 북 연타 |
| `ignite` / `beaconOut` | 봉화 점화/소등 | 불 붙는 소리 + 꽹과리 반짝임 / 징 한 번 길게 |
| `hammer`, `rise`, `crumble` | 건설·지형 | 원작 유지(나무·돌 소리는 문화 중립) |
| 번개(spire) | 전기음 | 벼락 + 짧은 방울(무구) 소리 |
| 대포(bombard) | 포성 | 그대로(조선 총통). 포차 시대 구분은 선택 사항. |

나머지 화살·칼·폭발·동전 소리는 문화 중립이므로 손대지 않는다. 바꾸는 범위를 좁혀야 믹스 균형이 유지된다.

## 검증

소리는 헤드리스로 들을 수 없다. 대신:
1. 예외 유무를 본다. 브라우저는 사용자 제스처 전까지 오디오를 막으므로 클릭으로 깨운 뒤 지켜본다. 출력에 `[EXCEPTION]`이 없어야 한다.
   ```bash
   python3 tools/build.py
   node tools/cdp.js "seed=4&ff=30" 1280,800 wait:2000 click:640,400 wait:9000 eval:"__cw.G.lives" 2>&1 | grep -v "GPU stall"
   ```
2. `OfflineAudioContext`로 각 효과음을 2초 렌더링해 **피크(<1.0, 클리핑 없음)와 RMS(무음 아님), NaN 없음**을 수치로 확인하는 스크립트를 `tools/`에 두어도 좋다. 필수는 아니다.
3. 변경한 효과음 이름 목록과 "들어 봐야 할 지점"을 보고서에 남겨 사람이 귀로 확인할 수 있게 한다.
