# army → audio (gugak-composer)

효과음 **키는 바꾸지 않았다.** 적이 사람·말·공성 병기가 되면서 같은 키가 불리는 상황만 달라졌다. 음색을 다듬을 때 참고:

| 키 | 지금 불리는 상황 (`src/61-monsters.js`) | 어울리는 소리 |
|---|---|---|
| `boneRattle` | 병사·기병·자객이 쓰러질 때(가장 자주) | 갑옷·무기가 떨어지는 짧은 쇳소리/둔탁한 소리 |
| `ratSqueal` | 기병(경기병·철기)이 쓰러질 때 gain 0.3 | 말 울음 |
| `batScreech` | 전투매/송골매가 떨어질 때 | 매 울음 |
| `hammer` | 충차·운제·누차가 부서질 때, 살리타의 돌 세례가 망루에 맞을 때 | 나무 부서지는 소리 / 돌 충돌 |
| `slash` | 대연(연)이 찢어질 때 | 천·종이 찢기는 소리 |
| `ignite` | 풍등이 터질 때, 독전관·적장이 증원을 부를 때 | 불붙는 소리 / 나발 짧은 신호 |
| `roar` | 적장 함성·호령·격노·쓰러짐 | 함성 또는 나각 |
| `bossStep` | 적장의 말발굽(반 걸음마다), 살리타의 호령 | 무거운 말발굽 |
| `squelch` | 적 쪽에서는 더 이상 쓰지 않음 | — |
