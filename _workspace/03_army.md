# 03 · 침공군과 적장 (army-modeler)

수정 파일: `src/50-rig.js`, `src/51-bestiary.js`, `src/61-monsters.js` (`src/62-game.js`는 손대지 않음 — 배너 문자열 그대로).
이름·설명은 `_workspace/01_lore_review.md`의 확정 이름표(109~177행)를 그대로 옮겼다.

## 구조

- **공용 사람 키트 `KIT.man`**(PartBatch 7개) 하나로 모든 병사·기수·적장을 그린다. 밝은 중립색 천 + 인스턴스 tint.
  원작의 해골/거인/오우거/골렘 키트 4벌(28개)과 쥐·슬라임·거미·늑대·망령·두꺼비 키트는 삭제.
- **군대 구분** = ① tint(`ARMY[curArmy()]`에서 계산, `ar_look()`) ② 군대별 머리 장비 `KIT.army[a].hat / .heavy` ③ 군대별 깃발 `KIT.army[a].flag`.
  - 수: 검은 찰갑 투구 + 황색 띠·꼭지 / 황색 군기
  - 당: 밝은 강철 투구 + 붉은 술 / 진홍 바탕 금빛 군기
  - 몽골: 모피 테 + 흰 펠트 털모자 / 검은 말총 술데(밤에 보이도록 금빛 꼭지와 청·백 드림 추가)
  - 왜: 진가사(검은 삿갓 + 흰 테 + 붉은 원), 중갑·적장은 가부토(밖으로 벌어진 금빛 뿔 앞꾸밈 — 초승달 아님) / 흰 바탕 붉은 띠 사시모노
  - 군대별 PartBatch는 그 군대의 전장에서만 인스턴스가 생긴다(n = 0이면 `visible = false`) → 드로콜 증가 없음.
- **말 `KIT.horse`**(몸통·다리·꼬리·마구·마갑 5개) + `ar_rigHorse` → 안장 행렬을 `rigHuman`의 `e.mount`로 넘겨 기수를 앉힌다.
- **공성 병기**: `KIT.ram`(충차 몸체·통나무), `KIT.ladder`(운제 수레), `KIT.stower`(누차), 공용 `KIT.wheel`.
- **비행체**: `KIT.bat`(매), `KIT.garg`(연 + 매달린 척후), `KIT.wisp`(풍등).
- 장면 전체 InstancedMesh 68개(아군·표식 포함, 군대별 배치는 넷 중 하나만 그려진다). `ff=45` 시점 드로콜 216~251. 원작 수치는 따로 재지 않았다.
- **눈빛 제거**: `EYES`·`def.eye` 삭제. 남은 광원은 풍등, 보졸·화공병의 횃불뿐. 깃발·투구 꼭지에 약한 자체 발광(emis .02~.06)을 줘 밤에 묻히지 않게 했다.
- 전장의 `bio.tints`(원작 괴물용)와 `bio.wispHex`는 더 이상 읽지 않는다 → `handoff/army-to-biome.md`.

### `rigHuman`에 더한 플래그 (기존 플래그 동작은 그대로)
`tintH`/`tintL`(부위별 tint), `mount`(안장 행렬), `crouch`(0..1 웅크려 달리기), `roll`(앞구르기), `charge`, `lance`, `hoist`, `girth`, `wTint`,
`gear: [{ b, at: 0 몸통|1 머리|2 골반, t, s, y, glow }]`(덧입는 장비 목록).
`cast`는 말 탄 상태에서는 오른팔만 든다(그 외는 원작과 동일). `KIT.foot`/`SPEC.foot`, `KIT.item.sword/torch/shieldR/helm/plate/club/hood/robe/staff/drum/standard/stick/keg/wraps/wrapHead/crown` 키는 모두 살아 있다(모양만 테마에 맞게 바뀜).

## 불변 계약 점검

- `MON`의 키, hp·spd·rad·mass·bounty·lives·dmg·atkT·armor·능력 필드(`split`, `hop`, `frenzy`, `slip`, `explode`, `ghost`, `aura`, `summon`, `regen`, `slowRes`, `stomp`, `enrage`, `alt`, `flap`, `glow`, `cat`), `ROSTER`, 웨이브·AI 로직: **변경 없음**. `queen.summon.type`도 `spider`(세작) 그대로 두었다(난이도 보존).
- 바꾼 것은 겉모습 필드뿐: `name/names/tip/tips/short`, `scale`(모델 크기), `top`(체력바 높이), `hitH`(화살이 겨누는 높이), `death`, `blade`(칼 휘두름 이펙트), `ride`(말 보폭), `eye`·`tint` 삭제.
  `scale`은 리그·이펙트 크기와 걸음 위상에만 쓰이고 충돌(`rad`)과 무관하다.

## 한계

- 사람은 팔다리가 상자인 한 가지 체형이다. 역사는 굵기 배율로만 덩치를 냈다.
- 말 다리는 무릎 관절 없이 통짜로 흔들린다. 기수의 창은 공격 때도 내려치는 동작을 쓴다(찌르기 동작 없음).
- 충차의 수레꾼은 지붕 안에 있다고 보고 그리지 않았다. 운제의 두 병사는 사다리와 한 개체(충돌 반지름 .3)라 앞 유닛과 살짝 겹칠 수 있다.
- 자객은 반투명 처리를 할 수 없어(불투명 인스턴스 재질) 연기 입자로만 "흐려짐"을 표현한다.
- 누차(높이 약 3)·적장 깃발(높이 약 5)은 길 위에 문·다리 구조물이 낮게 걸쳐 있으면 뚫고 지나간다.
- 효과음 키는 그대로 두고 쓰임새만 바꿨다(`handoff/army-to-audio.md`). 한글 HUD는 이 워크트리에서는 깨져 보인다(폰트는 다른 에이전트 담당).
