# tower-architect → hud-calligrapher

- `TOWER[kind].icon` 키(`archer`/`bombard`/`spire`/`guard`)는 그대로 두었습니다. 아이콘 그림을 바꾼다면: `archer` = 기와지붕 망루, `bombard` = 포차(투석기의 긴 팔. 조선에서는 총통이지만 아이콘은 하나로 충분), `spire` = 장대 위의 새(솟대), `guard` = 창 든 병사 또는 초가 초소.
- 이름·설명은 `_workspace/01_lore_review.md`의 확정표 그대로 넣었습니다. 가장 긴 설명 줄은 `총통과 진천뢰로 포격한다.`(14자), 가장 긴 이름은 `맥궁 망루`·`총통 포대`·`벼락 솟대`(5자). `towerShort()`는 모두 2자(`맥궁`, `각궁`, `편전`, `포차`, `총통`, `솟대`, `창병`, `별초`, `의병`).
- 지붕이 생겨 타워가 높아졌습니다. `mounts.top`(0→2단계): 망루 4.4 / 6.0 / 6.8, 포차 3.7 / 4.1 / 4.5(조선 총통 2.8 / 3.2 / 3.6), 솟대 3.6 / 4.3 / 5.0, 초소 2.4 / 2.7 / 3.9. `72-ui.js`는 `Math.min(3.4 또는 3.6, mounts.top)`으로 잘라 쓰므로 메뉴 위치는 원작과 같습니다. 메뉴가 지붕을 가린다고 느껴지면 그 상한만 조정하면 됩니다.
