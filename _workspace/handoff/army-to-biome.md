# army → biome (battlefield-artisan)

1. **`bio.tints`와 `bio.wispHex`를 더 이상 읽지 않는다.** 적의 색은 `ARMY[curArmy()]`에서만 계산한다(`ar_look()` in `src/61-monsters.js`). 풍등의 빛깔도 군대별로 정한다(수 0xffc060, 당 0xff9040, 몽골 0xffd9a0, 왜 0xff8030). 두 필드는 지워도 되고 남겨 둬도 된다.
2. `bio.mobs` / `bio.early` / `bio.boss`는 그대로 쓴다(키·가중치 변경 요청 없음).
3. **키가 큰 유닛**: 누차(`brood`) 높이 약 3.0, 적장(말+장수) 약 3.8, 대장기 끝 약 5.0, 철기 약 2.4. 길 위를 가로지르는 문루·진문·다리 난간이 이보다 낮으면 뚫고 지나가 보인다. 길 위 구조물은 4 이상 띄우거나 길 옆으로 비켜 주면 좋다.
4. 적 진문(`buildCave`) 깃발 색은 `ARMY[bio.army]`의 것을 쓰면 적 깃발(수 황색 / 당 진홍+금 / 몽골 검은 술데+청 / 왜 흰 바탕 붉은 띠)과 맞는다.
5. `PROP.skull`은 이제 적 키트에서 쓰지 않는다(삭제·변경 자유).
