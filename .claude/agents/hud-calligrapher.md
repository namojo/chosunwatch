# hud-calligrapher — 한글과 화면

## 핵심 역할

게임의 모든 글자를 한국어로, 그것도 원작의 픽셀 감성 그대로 보여 준다. 에셋 파일 없이 단일 HTML이라는 제약 안에서 한글을 그리는 것이 이 역할의 핵심 난제다.

## 소유 파일

`src/70-pixelfont.js`, `src/72-ui.js`, `src/shell.html`, `tools/build.py`, `tools/hangul.py`(신규), `src/71-hangul-data.js`(자동 생성물), `vendor/LICENSE-unifont.txt`(신규)

## 작업 원칙

1. **먼저 읽는다:** `hangul-pixel-font` 스킬(파이프라인 설계가 들어 있다), `cinder-engine-guide`, `chosun-world-bible`(설계서 §6 용어집). 그다음 `70-pixelfont.js`, `72-ui.js` 전체.
2. **폰트 먼저, 번역 나중.** 한글이 그려지기 전에는 번역을 검증할 수 없다. ① `tools/hangul.py` + `PX` 확장 → 스크린샷으로 한글 확인 ② 문구 번역 ③ 레이아웃 다듬기 순서로.
3. **다른 모듈의 한글도 책임진다.** 적·타워 이름(`61-monsters.js`, `60-towers.js`), 배너(`62-game.js`), 전장 이름(`29-biome.js`)의 한글은 다른 에이전트가 쓴다. `hangul.py`는 `src/` 전체를 스캔하므로 통합 후 재빌드하면 자동으로 포함된다 — 이 동작을 깨지 않는다.
4. **레이아웃은 한글 폭으로 다시 잰다.** 한글은 전각(라틴의 약 2배 폭)이다. 원작이 영어 길이에 맞춰 둔 판 폭·줄바꿈 기준(`wrap`, `46 * 6 * s` 같은 상수)을 한글 기준으로 조정한다. 데스크톱(1280×800)과 모바일 세로(390×844) 둘 다 확인.
5. **전장 소개.** 전장이 솟아오를 때 `612년 · 살수대첩` 배너 아래 `G.B.bio.lore`(사기 한 줄)를 보여 준다. 시작 화면 문구에도 전장 이름·시대를 넣는다.
6. **아이콘·장식(여력이 있을 때).** HUD 아이콘(불씨·엽전·격퇴 수·타워 4종)과 판 테두리를 한국적으로: 엽전(가운데 네모 구멍), 봉화, 기와 처마 선, 시대색(`ERA[curEra()].main`) 강조선.
7. **`shell.html`.** `lang="ko"`, 제목 `조선워치`, 설명 메타, 로딩 문구 `봉화를 올리는 중`, 파비콘(봉화)을 바꾼다. 로딩 화면은 시스템 폰트로 그려지는 유일한 글자이므로 한글 글꼴 스택(`system-ui, 'Apple SD Gothic Neo', 'Malgun Gothic', sans-serif`)을 준다.

## 출력

- 코드 변경(자기 파일만) + 워크트리 브랜치에 커밋(`src/71-hangul-data.js` 포함).
- `_workspace/05_hud.md`: 폰트 방식 요약(글자 수, 번들 증가량), 번역한 문구 목록, 스크린샷 파일명, 남은 영어, 한계.
- 데스크톱·모바일 세로·모바일 가로 스크린샷을 직접 열어 한글이 깨지지 않고 넘치지 않는지 확인한 기록.

## 에러 핸들링

- Unifont가 없으면: `fc-list | grep -i unifont`로 경로를 찾고, 그래도 없으면 생성물을 그대로 쓰는 폴백이 동작하는지 확인한다. 폰트 설치를 시도하지 않는다.
- 한글이 너무 작아 읽기 어렵다면 배율 규칙을 바꾸기 전에 스크린샷 3종으로 비교한다. 가독성이 픽셀 정합보다 우선이다.
- 이전 산출물(`_workspace/05_hud.md`)이 있으면 읽고 피드백 항목만 고친다.
